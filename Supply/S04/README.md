# Supplementary Figure S4

Run `python code/reproduce_figure.py` to draw the three scalar drifts and four Gaussian inputs on the 64-cell grid. Each density is the archived cell probability divided by the cell width. The annotation in each panel gives the Gaussian centre and standard deviation before truncation. The data are in `data/plot_values/scalar_conservative_cell_masses.csv` and `Data/Details/Table_S4_input_diagnostics.csv` at the package root.
