For the force fit, the original snapshots are supplied under both filenames expected by the recorded program. |

### Fig. 5, Fig. S5 and Supplementary Data 3

The archive names, original SHA-256 values and fields retained for replay are in `Source_Data/Additional_Source_Data/Reproduction_Inputs/inputs/retained_experiments/provenance.json`.

- **Fig. 5 shot budgets.** `Figures5_6_source_20261111.zip` contains `relative_accuracy/build_relative_data.py` and the 16 original experiment files. All 16 hashes matched the published accuracy protocol. Full source files and their lossless subsets yielded the same shot budgets. The exporter adds the common comparison-shot and target-derived resource-shot columns.
- **Fig. S5 trajectories.** The revised records use the same 32 × 32 grid and prepared inputs as Fig. 5. `Source/KvN/generate_fig_s5_trajectories.py` regenerates all 65 output times and checks the terminal probabilities and reference moments against the retained Fig. 5 records. It integrates the matched characteristics with eight-point Gauss–Legendre quadrature in each cell. The stored initial states and quadrature order are replayed by `trajectory_check.py`.
- **Supplementary Data 3.** The original programs and nine fit JSON records came from `Figure6/general_polynomial_mps/preparation/` in the same figure archive. The nine saved fit JSON files are no longer required: the producer deterministically refits all nine targets with the declared seeds using the canonical `Source.KvN.radial_mps` preparation code, executes the resulting circuits and formats the computed quality metrics at publication precision.

### Fig. S8a task time

`Source/RE/generate_supplement_data.py --s8-only` calculates the shot budget for the 1% relative field error target from `Shared_source_data/RE_common/Numerical_Details/input/joint_readout_inputs.npz`, evaluates the physical designs using the direct workload and the preparation file for physical error probability 0.0005, and selects the minimum-qubit and fastest capped design at each allowance. Total seconds equal accepted shots multiplied by seconds per attempt. The code takes its column order from `columns.json`. The eight published data rows can all be removed before the calculation.

From the integrated release root, run `python Codes/Source/RE/generate_supplement_data.py --s8-only --output Generated_Outputs/S8`. Add `--publish-figure-data` to write the local figure input, both auxiliary copies and the file checksums in `Source_Data/manifest.csv`.
